# Lunar Deploy Agent v1.0.0

Release Date: TBD

## Overview

Version 1.0.0 marks the first stable public release of Lunar Deploy Agent.

Lunar Deploy Agent is a lightweight deployment orchestration service written in Go that supports command-line execution, HTTP APIs, asynchronous deployment queues, real-time event streaming, health monitoring, deployment history, and PM2-based application deployments.

This release establishes the core architecture and public API surface that future releases will build upon.

---

# Highlights

## Deployment Engine

The deployment engine executes deployment pipelines composed of ordered deployment steps.

Supported deployment steps:

* git_pull
* shell
* npm_install
* npm_build
* pm2_restart
* pm2_start_or_restart
* pm2_save
* pm2_status
* http_health_check

Deployments stop immediately on failure and return detailed execution results.

---

## HTTP API

The agent can operate as a long-running deployment service.

Supported endpoints:

### Public

```text
GET /health
GET /openapi.yaml
GET /swagger/*
```

### Protected

```text
GET /status
GET /deployments
GET /history

GET /jobs
GET /jobs/{id}
DELETE /jobs/{id}

GET /queue

GET /node
GET /heartbeat

POST /deploy

GET /events
```

Authentication is provided through API bearer tokens.

---

## Asynchronous Deployment Queue

Deployments are processed through a background worker system.

Features:

* Job creation
* Job tracking
* Queue metrics
* Job cancellation
* Queue monitoring

Supported job states:

```text
queued
running
succeeded
failed
cancelled
```

---

## Real-Time Event Streaming

The agent includes a WebSocket event system.

Supported event categories:

### Deployment Events

```text
deployment_started
deployment_completed
deployment_failed
```

### Step Events

```text
step_started
step_completed
step_failed
```

### Job Events

```text
job_queued
job_running
job_succeeded
job_failed
job_cancelled
```
